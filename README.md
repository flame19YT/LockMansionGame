# LockMansionGame
Lock Mansion is a browser-based puzzle game with a soft clay / plasticine aesthetic. Your goal is to open locks by solving a wide variety of mini-puzzles.Each level features a different mechanic: drag shapes into the right slots, crack combination locks, find the matching key, pair cards, cut ropes, align rings, wait without touching, or catch a runaway button. Some levels are playful “troll” puzzles that subvert expectations.Clearing levels earns coins that you spend on the map to upgrade your mansion — roof, windows, garden, fountain, pool, cars, helicopter, and celebrity guests. The house evolves through three phases (Base House → Palace → Mega Villa).Features
75 levels + infinite bonus level
14 different puzzle types
Coin economy and mansion upgrades
Generative music (Lo-fi / Playful / Ambient) + sound effects
Paid hints and full solutions
Local progress saving
Mobile-first (landscape orientation)
Built entirely with vanilla HTML, CSS and JavaScript — no external dependencies.
